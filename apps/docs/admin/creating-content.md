# Creating Content

Learn how to create, edit, publish and manage content in the Admin Panel.

## Create New Content

1. Go to Content → Create New.
2. Select a schema.
3. Fill out fields.
4. Upload or select media.
5. Save as draft or publish.

## Drafts and Publishing

- Save as Draft: Stores content locally in the admin session.
- Publish: Commits content to your GitHub repository.

## Editing Content

- Click on any content item to open the editor.
- Make changes and save.
- View history to revert if needed.

## Deleting Content

- Use the delete action in the editor or list.
- Deleted files can be recovered via Git history.
