# Media Management

Manage uploaded images, videos and documents.

## Uploading Media

- Drag & drop or use the Upload button.
- Files are stored under the `media/` folder.
- For large files, consider Git LFS.

## Organizing Media

- Media is grouped by type.
- Use descriptive filenames.
- Prefer web-optimized formats (WebP, MP4 H.264).

## Inserting Media into Content

- Use the media picker inside the content editor.
- Media will be embedded with special tags supporting progressive loading.

## Best Practices

- Compress images before upload.
- Use descriptive alt text for accessibility.
- Avoid uploading uncompressed video files.
