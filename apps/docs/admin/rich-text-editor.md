# Rich Text Editor

Learn how to use the GitCMS rich text editor for creating formatted content.

## Features

The GitCMS editor (powered by TipTap) provides:

### Formatting

- Bold, italic, underline, strikethrough
- Headings (H1-H6)
- Lists (ordered, unordered)
- Blockquotes
- Code blocks with syntax highlighting
- Tables

### Media

- Insert images (drag & drop or upload)
- Embed videos
- Link to documents

### Advanced

- Links (internal and external)
- Text alignment
- Horizontal rules
- Character count

## Keyboard Shortcuts

- `Ctrl/Cmd + B` - Bold
- `Ctrl/Cmd + I` - Italic
- `Ctrl/Cmd + K` - Insert link
- `Ctrl/Cmd + Z` - Undo
- `Ctrl/Cmd + Shift + Z` - Redo

## Markdown Mode

Toggle to Markdown Mode to edit raw Markdown directly.
