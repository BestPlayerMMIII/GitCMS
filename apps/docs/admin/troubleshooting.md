# Troubleshooting

Common problems and how to fix them.

## Content Not Saving

- Ensure internet connection is stable.
- Verify GitHub OAuth permissions.
- Repository must not be archived.

## Media Upload Fails

- Check file size and type.
- Consider using Git LFS for large files.
- Try smaller batches.

## Schema Changes Not Applying

- Hard refresh the admin panel.
- Clear cache and sign out/in.
- Validate existing content against the new schema.
