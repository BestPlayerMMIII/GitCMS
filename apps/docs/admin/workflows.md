# Workflows

Common workflows for content creators.

## Writing a Blog Post

1. Navigate to Content → Create New
2. Select "Blog Post" schema
3. Fill in title and content
4. Upload featured image
5. Add tags and metadata
6. Click "Publish"

## Managing Portfolio Projects

1. Create "Project" schema with fields
2. For each project:
   - Create new "Project" content
   - Upload project screenshots
   - Add project details
   - Publish

## App Configuration

1. Create "App Config" schema
2. Create single config document
3. Update settings as needed
4. App fetches config on launch
