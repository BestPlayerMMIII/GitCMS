How It Works

// 1. Setup import { injectMediaStyles, MediaManager } from '@git-cms/client'; injectMediaStyles(); const mediaManager = new MediaManager({ repository: 'owner/repo', token: 'github-token', }); // 2. Fast Render (Thumbnails) const fastHtml = mediaManager.renderFast(content); container.innerHTML = fastHtml; // 3. Full Render (Actual Media) const fullHtml = await mediaManager.renderFull(content); container.innerHTML = fullHtml;

Features

  • ✅ Videos: Poster images with play button overlay
  • ✅ Audio: Icon placeholders with click-to-load
  • ✅ Documents: Thumbnail previews with download links
  • ✅ Images: Progressive loading from thumbnail to full-res
  • ✅ Performance: Fast initial render, load media on-demand
  • ✅ Private Repos: Authenticated requests for private content
